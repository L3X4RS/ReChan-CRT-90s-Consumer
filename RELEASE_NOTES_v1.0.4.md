# ReChan CRT 90s Consumer v1.0.4

## FINAL v2 + Geometry Fix

This release keeps the selected FINAL v2 visual profile while removing the frame-edge geometry artifacts found during testing.

### Highlights

- 90s consumer CRT-inspired color response
- Refined scanlines and vertical mask
- Subtle chromatic separation
- No temporal ghosting
- No heavy vignette
- No internal-resolution downsample
- Geometry fix for frame-edge distortion
