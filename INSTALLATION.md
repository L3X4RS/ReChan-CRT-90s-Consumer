# Installation / Instalação

## 🇺🇸 English

### Fresh install

1. Back up your existing `rechan.exe`.
2. Download the latest release:
   **[ReChan CRT 90s Consumer v1.1](https://github.com/L3X4RS/ReChan-CRT-90s-Consumer/releases/download/v1.1/ReChan_CRT_90s_Consumer_v1.1.zip)**
3. Extract the ZIP into your ReChan folder.
4. Replace the included files when prompted.
5. Verify:

```text
ReChan\~mods\90s Consumer\crtmod.dll
```

6. Start ReChan normally.

### Updating from v1.0

If your patched `rechan.exe` already loads:

```text
~mods\90s Consumer\crtmod.dll
```

you can normally update by replacing only `crtmod.dll`.

### Uninstall

Restore the original ReChan executable and remove:

```text
~mods\90s Consumer\
```

## 🇧🇷 Português

### Instalação nova

1. Faça backup do seu `rechan.exe` atual.
2. Baixe a versão mais recente:
   **[ReChan CRT 90s Consumer v1.1](https://github.com/L3X4RS/ReChan-CRT-90s-Consumer/releases/download/v1.1/ReChan_CRT_90s_Consumer_v1.1.zip)**
3. Extraia o ZIP dentro da pasta do ReChan.
4. Substitua os arquivos incluídos quando solicitado.
5. Confirme:

```text
ReChan\~mods\90s Consumer\crtmod.dll
```

6. Abra o ReChan normalmente.

### Atualizando da v1.0

Se o seu `rechan.exe` modificado já carrega:

```text
~mods\90s Consumer\crtmod.dll
```

normalmente basta substituir apenas o arquivo `crtmod.dll`.

### Desinstalação

Restaure o executável original do ReChan e remova:

```text
~mods\90s Consumer\
```
