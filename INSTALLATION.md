# Installation

## Fresh install

1. Back up your existing `rechan.exe`.
2. Extract `ReChan_CRT_90s_Consumer_v1.0.4_COMPLETE.zip` into your ReChan folder.
3. Replace files when prompted.
4. Verify:

```text
ReChan\~mods\90s Consumer\crtmod.dll
```

5. Start ReChan normally.

## Update from an older 90s Consumer build

If your current patched executable already looks for:

```text
~mods\90s Consumer\crtmod.dll
```

replace only the DLL with the newer version.

## Uninstall

Restore the original ReChan executable and remove:

```text
~mods\90s Consumer\
```
