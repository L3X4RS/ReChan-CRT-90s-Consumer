# ReChan CRT 90s Consumer v1.0

## 🇺🇸 English

The first public release of **ReChan CRT 90s Consumer**.

A custom CRT post-processing mod for ReChan, tuned around the look and character of a good 1990s consumer CRT television while preserving ReChan's normal rendering resolution.

### Highlights
- Refined CRT scanlines
- Subtle phosphor-style vertical mask
- Controlled color response
- Mild RGB separation
- Very light analog noise and flicker
- No temporal ghosting
- No heavy vignette
- No fake 240p downsample
- Clean frame edges

### Installation
Extract the complete release package into your ReChan folder and replace files when prompted.

The mod DLL should be located at:

```text
ReChan\~mods\90s Consumer\crtmod.dll
```

## 🇧🇷 Português

Primeira versão pública do **ReChan CRT 90s Consumer**.

Um mod de pós-processamento CRT para o ReChan, ajustado para reproduzir o caráter visual de uma boa TV CRT doméstica dos anos 90, mantendo a resolução normal de renderização do ReChan.

### Destaques
- Scanlines CRT refinadas
- Máscara vertical de fósforo sutil
- Resposta de cores controlada
- Separação RGB leve
- Ruído analógico e flicker muito discretos
- Sem ghosting temporal
- Sem vinheta pesada
- Sem falso downsample para 240p
- Bordas limpas

### Instalação
Extraia o pacote completo da release dentro da pasta do ReChan e substitua os arquivos quando solicitado.

O DLL do mod deve ficar em:

```text
ReChan\~mods\90s Consumer\crtmod.dll
```
