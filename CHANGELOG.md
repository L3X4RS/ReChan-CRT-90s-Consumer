# Changelog

## v1.1

### English
- Refined the CRT presentation toward a more authentic 1990s consumer-TV look.
- Added luminance-reactive beam / scanline behavior.
- Stabilized the scanline raster.
- Added separate luminance and chroma bandwidth treatment.
- Added mild horizontal chroma softness and very subtle color bleed.
- Added subtle highlight beam / phosphor spread.
- Reworked the mask into a gentle RGB phosphor-style triad.
- Reduced RGB convergence so it reads less like modern chromatic aberration.
- Preserved native ReChan rendering resolution.
- No temporal ghosting, fake 240p, heavy vignette, TV bezel or border warp.

### Português
- Apresentação CRT refinada para ficar mais próxima de uma TV doméstica dos anos 90.
- Feixe / scanlines agora reagem à luminância.
- Raster das scanlines estabilizado.
- Tratamento separado para largura de banda de luminância e crominância.
- Suavização horizontal da cor e bleed cromático muito sutis.
- Pequeno espalhamento de highlights lembrando feixe / fósforo.
- Máscara refeita como uma tríade RGB de fósforo discreta.
- Convergência RGB reduzida para não parecer aberração cromática moderna.
- Resolução normal de renderização do ReChan preservada.
- Sem ghosting temporal, falso 240p, vinheta pesada, moldura de TV ou warp nas bordas.

## v1.0

### English
- First public release of ReChan CRT 90s Consumer.
- Refined CRT scanlines and vertical phosphor-style mask.
- Tuned color response and midtones.
- Subtle chromatic treatment.
- No temporal ghosting.
- No heavy vignette.
- No fake 240p downsample.
- Clean frame edges without visible border deformation.

### Português
- Primeira versão pública do ReChan CRT 90s Consumer.
- Scanlines CRT refinadas e máscara vertical de fósforo.
- Resposta de cores e médios ajustados.
- Tratamento cromático sutil.
- Sem ghosting temporal.
- Sem vinheta pesada.
- Sem falso downsample para 240p.
- Bordas limpas, sem deformação visível no contorno.
